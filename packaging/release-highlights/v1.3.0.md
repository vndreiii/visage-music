- **Lyric scenes:** a **3D corridor** where the sung line is sharp and the rest fall away, and **Cuts**, a vinyl-groove look where rings slice the lettering and react to the music. Cuts can follow the Rings background or run on their own clock and reactivity. Lines also bounce into place like a spring (Settings → Lyrics → Motion).
- **Fits any window:** the layout adapts from a phone-sized window to an ultrawide monitor, with menu and queue/lyrics trays on small windows. A **pop-out mini player** (Ctrl+Shift+M) shows lyrics when it is wide enough.
- **Settings redesigned:** every page rebuilt with live previews, dropdowns instead of chip rows, options that appear only when they apply, and search.
- **Tag Manager:** auto-tagging with a review screen where you can type your own values, a right-click menu, drag-select, and background work with a draggable progress button that now also shows library scans.
- **Carry tracks anywhere:** drag a track from the queue, the now-playing card or a library list onto a playlist or folder.
- **Local library:** several music folders with per-folder scan status and a search bar for the current tab.
- **Playback:** every remaining stream source is tried before a song fails; a refused first source no longer shows "loading failed".
- **Lyrics:** translation is skipped when a song is already in your language, the delay buttons in the player have no limit, and LRCLIB no longer picks a different song with the same title (#2).
- **Windows and Linux:** square window corners whenever the window fills the screen, and the pop-out player no longer lags on Hyprland while the main window is hidden.
- **Home and pages:** a tidier Home (avatar headers, multi-row Quick picks), loading placeholders that match each page, and narrow-window fixes for your playlists and the library sidebar.
